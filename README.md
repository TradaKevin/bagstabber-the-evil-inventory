# BAGSTABBER: The Evil Inventory

BAGSTABBER is a darkly comedic 3D game created for Evil Game Jam 2026 using Unity and C#.

You play as a cursed backpack carried by an automatic fantasy hero. During each dangerous encounter, the hero requests a useful item. You decide whether to help by giving the correct item or secretly sabotage the journey with something harmful.

Harmful choices earn Evil Points, but they also reduce the hero’s health and increase suspicion. If the hero dies or discovers your true identity, your evil plan fails. Keep the hero alive long enough to reach the Royal Vault, unlock the Betrayal Seal, steal the treasure, and complete the final betrayal.

## Core Features

* 3D dungeon environment made with Unity URP
* Drag-and-drop inventory gameplay
* Automatic hero movement and encounters
* Helpful and harmful item choices
* Health, Suspicion, Evil and Treasure systems
* Multiple comedic encounter outcomes
* Final Royal Vault betrayal
* Stylized dark-fantasy presentation

## Engine and Tools

* Unity 3D
* Universal Render Pipeline
* C#
* TextMeshPro
* Unity UI
